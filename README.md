# Smart Air Traffic Control System

## Problem Statement

Developing smart air traffic control system using singly linked list.

## Objective

To implement aircraft record management using a linked list and perform basic operations such as adding, displaying, searching, updating, and deleting records.

## Data Structure Used

- Singly Linked List

## Operations

- Add Aircraft
- Display Aircraft Schedule
- Search Aircraft
- Update Aircraft Status
- Delete Aircraft
- Exit

## Concepts Used

- C++
- Singly Linked List
- Pointers
- Dynamic Memory Allocation
- Structures
- Searching and record management

## Algorithm

1. Start the program.
2. Create an empty linked list for aircraft records.
3. Display the menu of available operations.
4. Add a new aircraft record to the end of the list, ensuring its flight ID is unique.
5. Display all aircraft records by traversing the list.
6. Search for an aircraft using its flight ID.
7. Update the status of an aircraft using its flight ID.
8. Delete an aircraft record using its flight ID.
9. Repeat the menu operations until the user selects Exit.
10. Free the allocated memory and stop the program.

## Advantages

- Aircraft records can be added and removed dynamically.
- Flight IDs help identify and search for specific records.
- Aircraft details can be displayed and updated easily.
- Dynamic memory allocation allows the list to grow as needed, subject to available memory.

## Conclusion

The Smart Air Traffic Control System demonstrates the use of a singly linked list in C++ to manage aircraft records. It supports adding, displaying, searching, updating, and deleting records, helping illustrate pointers, dynamic memory allocation, and linked-list traversal.
